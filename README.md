# local-promo

Workspace for the evidence-gated promotion demo. Each top-level `platform-*`
folder is one GitHub repo; `platform-fleet` holds the Taskfile that creates
and syncs them (`task repos:create`). Start at
[platform-fleet/README.md](platform-fleet/README.md) and
[platform-fleet/NOTES.md](platform-fleet/NOTES.md).

Lessons from the first live run, and a checklist for the next demo: [LESSONS.md](LESSONS.md).
